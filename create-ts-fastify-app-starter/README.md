# @lingcoo-tech/create-ts-fastify-app-starter

The official project generator for [Lingcoo TS Fastify App Starter](https://github.com/LingcooTech/ts-fastify-app-starter).

```bash
npx @lingcoo-tech/create-ts-fastify-app-starter@latest my-app
```

The generator creates an independent pnpm workspace, initializes Git, and installs dependencies by default. Use `--skip-install`, `--no-git`, or `--ref <branch-or-tag>` to customize the process.
